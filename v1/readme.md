# Заметки
Первоочередной задачей является импорт данных из .txt или .excel файлов (карт адресов). В .txt или .excel должно храниться описание сигналов согласно протоколу Modbus RTU

Результатом импорта должны являтся 
* Данные - записи (строки) содержащие
	1. Наименование
	2. Примечание (Комментарий)
	3. Модбас адрес
	4. Модбас бит
	5. Модбас тип данных
	6. Модбас функцию(ии) - например может быть одновременно 3 и 6 функции
	7. Модбас значение для записи (если указывается подряд )
	8. (Не обязательно) Тип записи (1 - команда, 2 - уставка, 3 - запись измеряемого значения, 4 - запись калибровочного значения, 5 - чтение значения, 6 - чтение бита)

* Метаданные - дополнительная информация о данных (записях), представляет собой структуру словарь. Ключ - индекс записи в данных, значение - массив параметров
	1. Имеется ли уровень заголовка
	2. Тип записи 

Результатом экспорта является файл на выходе
* Например карта адресов для МЭК61850 может содержать в себе строки
	1. МЭК61850 MMS адрес
	2. МЭК61850 Goose адрес
	3. МЭК61850 адрес датасета
	4. МЭК61850 адрес отчета
	5. МЭК61850 адрес буферизированного отчета


Данные являются записями

## Примечания
* Если такая строка '189 (int16,write 6 187 188, value 0 951) - Уставка дискретного выхода 6', значит нужно сначала записать в адреса 187, 188 функцией модбас 6, значения 0 и 951 соответственно, а затем записать желаемое значение в адрес 189, функцией модбас 6
* Если '189 (int16,write 6 187 188, value 0 951) - Уставка дискретного выхода 6' после 'write' три числа, а после 'value' два числа, то значит первое число после 'write' является номером функции модбас, если чисел одинаковое количество, то соответственно все числа после 'write' являются адресами и все числа после 'value' являются значениями для записи
* Если 'cmd (int16,write 6 181 182 183, value 0 767 801) - Запустить тест АБ' то это команда, т.е. значения после 'value' отправляются по адресам после 'write 6' функцией 6 модбас, 
* Если '670 (int16,write,value 2) - Включить периодичность теста - еженедельно', значит число 2 записывается по адресу 670. Если функция после 'write' не указана, то исходим из типа данных, если 'int16' (1 слово), то используем функцию модбас 6, если 'float32', то используем функцию 16 модбас, если 'coil', то используем функцию 5 модбас

## Алгоритм парсинга строки
### Парсинг адреса
* 13 - обычный адрес
* 13.3 - адрес 13 и бит 3
* cmd - значит далее идет команда

### Парсинг параметров
* Первым параметром ВСЕГДА идет тип данных модбас
	1. uint16, int16
	2. uint32, uint32
	3. float16
	4. float32
	5. coil - это так называемые койлы (данные сигналы могут быть либо нулем либо единицей), для их чтения в модбас используются функции 1 или 2, а для записи 5 (один койл) или 15 (множество койлов)
